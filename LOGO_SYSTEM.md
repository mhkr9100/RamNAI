# RamN AI Logo & Icon System

This document tracks the correct icons for key brand elements within the application to prevent displacement and ensure consistency.

## 1. RamN AI (Main Brand)
- **Component:** `RamanIcon`
- **File:** `components/icons/RamanIcon.tsx`
- **Usage:** Used for the main app logo, navigation bar, and general branding.

## 2. Prism (The Meta Agent)
- **Component:** `PrismIcon`
- **File:** `components/icons/PrismIcon.tsx`
- **Usage:** Specifically represents the "Prism" Meta Agent brain and individual Prism-specific UI elements.

## 3. The Spectrum (Management Layer)
- **Component:** `SpectrumIcon`
- **File:** `components/icons/SpectrumIcon.tsx`
- **Usage:** Represents the agent management workspace and tool orchestration.

## 4. UserMap (Context Memory)
- **Component:** `UserMapIcon`
- **File:** `components/icons/UserMapIcon.tsx`
- **Usage:** Represents the long-term memory and context extraction engine.

---

**CRITICAL RULE:** Do not use `PrismIcon` when representing `RamN AI` generally. Always use `RamanIcon` for the product brand.
